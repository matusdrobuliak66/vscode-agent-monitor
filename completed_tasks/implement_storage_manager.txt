DATABASE SCHEMA:
1. file_hashes table:
   - id (PRIMARY KEY)
   - hash (UNIQUE, BLAKE3)
   - content (TEXT)

2. telemetry_logs table:
   - id (PRIMARY KEY)
   - timestamp (INTEGER, Unix timestamp)
   - method (TEXT)
   - request_data_hash (FOREIGN KEY -> file_hashes.id)
   - response_data_hash (FOREIGN KEY -> file_hashes.id, nullable)

3. security_findings table:
   - id (PRIMARY KEY)
   - telemetry_id (FOREIGN KEY -> telemetry_logs.id)
   - line_num (INTEGER)
   - severity (TEXT: High/Medium/Low)
   - pattern_type (TEXT: ApiKey/Password/HighEntropy)
